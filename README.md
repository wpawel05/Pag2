# PAG2 - wyznaczanie tras

Projekt zaliczeniowy: algorytmy Dijkstra i A*, rozszerzenie: trasy specjalne

Autorzy: Antoni Gromek, Hubert Tyl, Paweł Wesołowski

## Uruchomienie

Otwórz `index.html` przez Live Server (VS Code) albo `python -m http.server 8000` i wejdź na http://localhost:8000.

## Źródła

MapLibre GL JS, OpenFreeMap, Esri World Imagery.
